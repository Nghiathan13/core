## Overview

Stack: Tauri 2 + Vanilla TypeScript + Vite.

| Layer      | Role |
| ---------- | ---- |
| `app`      | Global initialization: providers, router, styles, entry point. No business logic or page/feature UI. |
| `pages`    | Route-level composition, owns page logic (UI, forms, validation, fetching, state). Keep code in the page until extraction is justified. |
| `features` | Independent, reusable user interactions with a narrow responsibility and a single shared implementation. Extract only when used in multiple places. |
| `entities` | Reusable domain models (types, logic, state). Starting without this layer is valid. |
| `shared`   | Infrastructure with no business logic, organized by segment (`ui`, `lib`, `api`, ...). May contain app-aware code (route constants, endpoints, DTOs). |
